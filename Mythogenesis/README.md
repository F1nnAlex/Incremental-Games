# Mythogenesis

A multi-day cosmic creation-myth incremental game. Shape raw Aether into the four Primordial Elements, weave geometric Constellations across an interactive star map, bargain with rival Deities in Mythic Trials, and shatter the cosmos into a New Age.

Open `index.html` in a browser (no build step). Progress saves automatically in `localStorage` under `mythogenesis_save_v1`.

## Layers & Pacing

Designed for multi-day progression where each successive reset layer introduces a new core mechanic and takes noticeably longer on average than the previous one:

1. **Primordial Void (`Aether`):** Spark the void (`Space`) and build a chain of Aether Conduits (*Wisp → Current → Wellspring → Nexus*, plus *Vortex* and *Astral Loom* unlocked later).
2. **Elemental Condensation (`Flame`, `Tide`, `Stone`, `Gale` Essence):** Choose which Element absorbs each reset. Elements empower each other in a clockwise cycle (`Flame → Tide → Stone → Gale → Flame`), rewarding balanced rotations and Cycle Harmony.
3. **The Firmament (`Starlight` & Interactive Star Map):** Spend Starlight to ignite 12 Stars across four alignments and weave limited Astral Threads into geometric **Triads** and **Elemental Bridges**.
4. **The Pantheon (`Devotion`):** Upgrade Patron Shrines, attune active Blessings & Sacrifices, and conquer 4 rule-bending **Mythic Trials** for permanent Relics.
5. **Ragnarok (`Creation Echoes`):** Reach `1.80e308` Aether with all 4 Relics to Shatter the Cosmos, buy **Break the Firmament**, unlock Constellation Presets and **Pantheon Accord**, and climb toward Apotheosis (`1e2,500` Aether).
